<h1 align="center">Nintendall</h1>

<p align="center"><b>One app for your Nintendo games, from NES to Wii U.</b></p>

Pick a game and Nintendall works out which console it's for and starts the right
emulator. Every emulator is built in, so there's nothing else to install or set up.

## Download

1. Download **Nintendall-setup.exe** from the
   [latest release](https://github.com/exultantliving0/Nintendall-Project/releases/latest).
2. Run it. If Windows says it protected your PC, click **More info**, then **Run anyway**.

Needs Windows 10 or 11.

## Getting started

1. Put your games in **Documents\Nintendall\Games**, in the folder for their
   console (NES, SNES, GameCube, Wii U...).
2. Open Nintendall, click a console at the top, then click a game's box to play.

New games show up by themselves, with their box covers. You need your own game
files; none are included.

## Consoles

NES, SNES, Nintendo 64, Game Boy, Game Boy Color, Game Boy Advance, Nintendo DS,
Nintendo 3DS, GameCube, Wii and Wii U.

Wii U disc images need keys from your own console: add them with
**Options > Wii U Keys...**.

## What you can do

- **Play with any controller:** Xbox, PlayStation, Switch Pro, 8BitDo and more.
  Change the buttons in **Options > Button Config**.
- **Play with friends** on other computers: **Multiplayer > Host Game** and
  **Join Game**.
- **Keep your saves** in **Documents\Nintendall\Saves**. You can bring saves from
  other emulators too (Dolphin, Cemu, Citra, Project64, mGBA...).
- **Save and load anywhere** with save states (F5 / F9).
- **Make it look retro** with the **Shaders** menu: old TV scanlines or a Game Boy screen.
- **Show what you're playing on Discord**, by itself while Discord is open.
- **Stay up to date:** Nintendall tells you when a new version is out and updates itself.

## Keyboard shortcuts

| Key | Does |
|---|---|
| Ctrl+O | Open a game |
| Ctrl+P | Pause |
| F5 / F9 | Save / load state |
| Hold Tab | Fast forward |
| F11 | Fullscreen |
| F12 | Screenshot |
